# Day 15 - UDF Practice

## Project Title
Customer Transaction Risk Analyzer

## Objective

The objective of this project is to understand User Defined Functions (UDFs) in Apache Spark and use them to classify customer transactions based on transaction values.

## Technologies Used

- Scala 2.12.18
- Apache Spark 3.5.3
- Spark SQL
- sbt 2.0.7
- Java 17
- CSV
